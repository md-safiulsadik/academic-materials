3-to-8 Decoder from 2-to-4 Decoders

A Logisim Implementation using 74-series Logic

Components Used

74LS139: Dual 2-to-4 Decoder/Demultiplexer

This IC is perfect for the task as it contains two independent 2-to-4 decoders. We'll use both decoders within a single chip to create our larger 3-to-8 decoder.

74LS04: Hex Inverter (NOT Gate)

This IC contains six NOT gates. We only need one to invert the most significant input bit, which will be used to select between the two decoders.

Logisim Circuit Diagram

Circuit Logic Explained

The most significant bit, **C**, acts as the master switch.

  • When **C = 0**, the top decoder is enabled (since its `/E` pin is active-low), and it decodes inputs A and B to activate one of the outputs from **Y0 to Y3**.
  • When **C = 1**, the signal is inverted by the NOT gate to become 0. This enables the bottom decoder, which decodes inputs A and B to activate one of the outputs from **Y4 to Y7**.
