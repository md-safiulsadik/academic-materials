Q1: Perform BCD addition for the decimal numbers (34)10 and (52)10.

Solution:

1. Convert to BCD:
34 → 0011 0100
52 → 0101 0010

2. Add the BCD numbers: 

  0011 0100
+ 0101 0010
-----------
  1000 0110

3. Check each 4-bit group. The left group is 1000 (8) and the right group is 0110 (6). Both are valid (<=9). No correction is needed.

Final BCD result: 1000 0110, which is (86)10.

Q2: Perform BCD addition for the decimal numbers (98)10 and (79)10.

Solution:

1. Convert to BCD:
98 → 1001 1000
79 → 0111 1001

2. Add the BCD numbers: 

    1 (carry)
  1001 1000
+ 0111 1001
-----------
 1 0001 0001

3. Correct the result. The right group sum is 1000 + 1001 = 10001. The 4-bit result is 0001 with a carry. Since the sum is > 9, we add 6: 0001 + 0110 = 0111 (7).

4. Add the left group with the carry: 1 + 1001 + 0111 = 10001. The 4-bit result is 0001 with a carry. Since the sum is > 9, we add 6: 0001 + 0110 = 0111 (7).

5. The carry out from the left group forms a new BCD group: 0001 (1).

Final BCD result: 0001 0111 0111, which is (177)10.

Q3: Represent the numbers (690)10 and (1000)8 in BCD, and then show the steps necessary to form their sum in BCD.

Solution:

1. Convert (1000)8 to decimal: 1 * 83 = 51210.

2. The two decimal numbers are 690 and 512.

3. Convert both to BCD:
690 → 0110 1001 0000
512 → 0101 0001 0010

4. Perform BCD addition: 

  0110 1001 0000
+ 0101 0001 0010
-----------------
  1011 1010 0010

5. Correct the invalid groups (>9):
Right group (0010) is valid (2).
Middle group (1010) is invalid. Add 6: 1010 + 0110 = 1 0000. Result is 0, carry 1.
Left group (1011). Add carry: 1011 + 1 = 1100. Invalid. Add 6: 1100 + 0110 = 1 0010. Result is 2, carry 1.

6. Assemble the final result with the new carry: 0001 0010 0000 0010, which is (1202)10.

Q4: Perform BCD addition between the two numbers (23D)16 and (F67)16 using their BCD representations.

Solution:

1. Convert hex to decimal:
(23D)16 = 57310.
(F67)16 = 394310.

2. Convert decimal to BCD:
573 → 0000 0101 0111 0011 (Padded)
3943 → 0011 1001 0100 0011

3. Perform BCD addition: 

  0000 0101 0111 0011
+ 0011 1001 0100 0011
-----------------------
  0011 1110 1011 0110

4. Correct invalid groups:
- Right group (0110) is 6. Valid.
- 2nd group (1011) is 11 (>9). Invalid. Add 6: 1011 + 0110 = 1 0001. Result is 1, carry 1.
- 3rd group (1110) is 14. Add carry: 1110 + 1 = 1111. Invalid. Add 6: 1111 + 0110 = 1 0101. Result is 5, carry 1.
- Left group (0011). Add carry: 0011 + 1 = 0100. Result is 4. Valid.

5. Assemble the corrected groups: 0100 0101 0001 0110, which is (4516)10.

Q5: What is the largest 3-digit decimal number that can be represented in BCD? Convert its BCD form to binary and hexadecimal.

Solution:

1. The largest 3-digit decimal number is 999.

2. Its BCD representation is 1001 1001 1001.

3. To convert this BCD form to binary, we treat the 12 bits as a single binary number: 1001100110012.

4. To convert this same BCD bit pattern to hexadecimal, we group the bits into sets of 4 (which they already are): 1001 1001 1001. This gives 99916.
(Note: This is different from converting the decimal value 999 to hex, which would be 3E716).

Q6: Perform BCD addition on (11101100)2 and (10100100)2 after converting them to BCD.

Solution:

1. Convert binary to decimal:
(11101100)2 = 23610.
(10100100)2 = 16410.

2. Convert decimal to BCD:
236 → 0010 0011 0110
164 → 0001 0110 0100

3. Add the BCD numbers:

  0010 0011 0110
+ 0001 0110 0100
-----------------
  0011 1001 1010

4. Correct the invalid group:
Right group (1010) is invalid. Add 6: 1010 + 0110 = 1 0000. Result 0, carry 1.
Middle group (1001). Add carry: 1001 + 1 = 1010. Invalid. Add 6: 1010 + 0110 = 1 0000. Result 0, carry 1.
Left group (0011). Add carry: 0011 + 1 = 0100. Valid.

5. Assemble the result: 0100 0000 0000, which is (400)10.

Q7: Perform BCD addition for (18)₁₀ and (29)₁₀.

Solution:

1. Convert to BCD:
18 → 0001 1000
29 → 0010 1001

2. Add the BCD numbers: 

  0001 1000
+ 0010 1001
-----------
  0011 0001  (carry from right group)

3. Right group: 1000 + 1001 = 10001. The sum is > 9. Result is 0001 with a carry. Correct by adding 6: 0001 + 0110 = 0111 (7).

4. Left group: 0001 + 0010 + 1 (carry) = 0100 (4). This is valid.

Final BCD result: 0100 0111, which is (47)10.

Q8: Which of the following 4-bit groups are invalid in the BCD system: 1010, 0111, 1100, 1001? Explain why.

Solution:

The invalid BCD groups are 1010 and 1100.

Reason: BCD represents decimal digits 0 through 9. A 4-bit group can represent values from 0 to 15. The binary values for 10 through 15 do not correspond to any single decimal digit, so they are considered invalid in the BCD system.
- 1010 = 10 (Invalid)
- 0111 = 7 (Valid)
- 1100 = 12 (Invalid)
- 1001 = 9 (Valid)

Q9: Convert the octal number (77)₈ to its decimal equivalent, and then represent the result in BCD.

Solution:

1. Convert octal to decimal: (77)₈ = 7 * 8¹ + 7 * 8⁰ = 56 + 7 = 63₁₀.

2. Convert the decimal result (63) to BCD.

3. BCD of 6 is 0110. BCD of 3 is 0011.

Final BCD result: 0110 0011.

Q10: Perform BCD subtraction of (48)₁₀ from (91)₁₀ using 9's complement BCD arithmetic.

Solution:

1. Find the 9's complement of the subtrahend (48). The 9's complement of 48 is 99 - 48 = 51.

2. Perform BCD addition of the minuend (91) and the 9's complement (51).

3. Convert to BCD:
91 → 1001 0001
51 → 0101 0001

4. Add them: 

  1001 0001
+ 0101 0001
-----------
  1110 0010

5. Correct the left group (1110) as it's > 9. Add 6: 1110 + 0110 = 1 0100. Result is 4, carry 1 (end-around carry).

6. The intermediate result is 0100 0010 with an end-around carry of 1.

7. Add the end-around carry to the result: 0100 0010 + 1 = 0100 0011.

Final BCD result: 0100 0011, which is (43)10. (Check: 91 - 48 = 43).
