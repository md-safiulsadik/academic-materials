Q1: The roots of the quadratic equation x2 - (14)bx + (44)b = 0 are x=5 and x=8. Determine the base b.

Solution:

1. Sum of roots: 5 + 8 = 13. From the equation, the coefficient is (14)b = b + 4. So, b + 4 = 13 → b = 9.

2. Product of roots: 5 × 8 = 40. From the equation, the constant is (44)b = 4b + 4.

3. Verify with the product: 4(9) + 4 = 36 + 4 = 40. The value matches. Thus, the base is 9.

Q2: Convert the hexadecimal number (1B9.F8)16 to its equivalent octal representation.

Solution:

1. Convert each hex digit to a 4-bit binary string: 1→0001, B→1011, 9→1001, F→1111, 8→1000.

2. Combine: (0001 1011 1001 . 1111 1000)2.

3. Group into 3-bit sets from the radix point: (000 110 111 001 . 111 110 000)2.

4. Convert each 3-bit group to octal: (671.76)8.

Q3: Given the multiplication (14)x × (5)x = (74)x, determine the value of the base x.

Solution:

1. Convert to base 10: (x + 4) × 5 = 7x + 4.

2. Solve for x: 5x + 20 = 7x + 4 → 16 = 2x → x = 8.

Q4: If √(41)b = 5, what is the value of the base b?

Solution:

1. Square both sides: (41)b = 52 = 25.

2. Convert to base 10: 4b + 1 = 25.

3. Solve for b: 4b = 24 → b = 6.

Q5: In base r, the subtraction (412)r - (133)r results in (257)r. Determine the base r.

Solution:

1. Analyze the rightmost column: 2 - 3 results in 7. This implies a borrow.

2. The equation for this column is (2 + r) - 3 = 7.

3. Solve for r: r - 1 = 7 → r = 8.

Q6: Convert the decimal number (250.5)₁₀ to base 2, base 8, and base 16.

Q7: Find the value of x if (211)ₓ = (152)₈.

Solution:

1. Convert both sides to base 10:
(211)ₓ = 2x² + x + 1.
(152)₈ = 1*8² + 5*8¹ + 2*8⁰ = 64 + 40 + 2 = 106.

2. Set them equal: 2x² + x + 1 = 106 → 2x² + x - 105 = 0.

3. Solve the quadratic equation. Factoring gives (2x + 15)(x - 7) = 0.

4. The possible solutions are x = -15/2 and x = 7. Since a base must be a positive integer, x = 7.

Q8: Perform the arithmetic operation (475)₈ + (256)₈.

Solution:

1. Rightmost column: 5 + 6 = 11. In base 8, 11 is 1*8 + 3. Write down 3, carry 1.

2. Middle column: 7 + 5 + 1(carry) = 13. In base 8, 13 is 1*8 + 5. Write down 5, carry 1.

3. Leftmost column: 4 + 2 + 1(carry) = 7. Write down 7.

The result is (753)₈.

Q9: What is the 10's complement of the decimal number 18?

Solution:

The formula for the 10's complement of an n-digit number N is 10ⁿ - N.

For the number 18 (which has 2 digits, so n=2), the 10's complement is 10² - 18 = 100 - 18 = 82.

Alternatively, find the 9's complement (99 - 18 = 81) and add 1 (81 + 1 = 82).

Q10: Determine the value of base x if (193)ₓ = (623)₈.

Solution:

1. Convert both sides to base 10. Note that for (193)ₓ to be a valid number, the base x must be greater than the largest digit, so x > 9.

(193)ₓ = 1*x² + 9*x¹ + 3*x⁰ = x² + 9x + 3.

(623)₈ = 6*8² + 2*8¹ + 3*8⁰ = 6*64 + 16 + 3 = 384 + 16 + 3 = 403.

2. Set them equal: x² + 9x + 3 = 403 → x² + 9x - 400 = 0.

3. Solve the quadratic equation: (x + 25)(x - 16) = 0.

4. The solutions are x = -25 and x = 16. Since the base must be positive, x = 16.

Q11: Convert (525)₁₀ to base 5.

Solution:

Use successive division by the target base (5).

525 / 5 = 105 remainder 0

105 / 5 = 21 remainder 0

21 / 5 = 4 remainder 1

4 / 5 = 0 remainder 4

Reading the remainders from bottom to top gives (4100)₅.

Q12: Perform the subtraction (1101)₂ - (1011)₂ using 2's complement.

Solution:

1. Find the 2's complement of the subtrahend (1011). First, find the 1's complement by inverting the bits: 0100.

2. Add 1 to the 1's complement: 0100 + 1 = 0101. This is the 2's complement.

3. Add the first number to the 2's complement:

4. Since there is a carry out (the leading 1), we discard it. The result is positive.
