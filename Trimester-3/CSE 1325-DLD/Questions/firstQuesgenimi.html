Q1: The roots of the quadratic equation x2 - (14)bx + (44)b = 0 are x=5 and x=8. Determine the base b.

Solution:

For a quadratic equation ax2 + bx + c = 0, the sum of roots is -b/a and the product of roots is c/a.

1. Sum of roots: 5 + 8 = 13. From the equation, the coefficient is (14)b. So, (14)b = b + 4. Equating them: b + 4 = 13 → b = 9.

2. Product of roots: 5 × 8 = 40. From the equation, the constant is (44)b. So, (44)b = 4b + 4.

3. Verify with the product: 4(9) + 4 = 36 + 4 = 40. The value matches. Thus, the base is 9.

Q2: Convert the hexadecimal number (1B9.F8)16 to its equivalent octal representation.

Solution:

1. Convert each hex digit to a 4-bit binary string:
1 → 0001, B → 1011, 9 → 1001, F → 1111, 8 → 1000.

2. Combine them: (0001 1011 1001 . 1111 1000)2.

3. Group the binary digits into sets of 3, starting from the radix point:
Integer part: (000 110 111 001)2. Fractional part: (111 110 00)2. Add trailing zeros to complete the last group: (111 110 000)2.

4. Convert each 3-bit group to its octal equivalent:
000→0, 110→6, 111→7, 001→1. Fractional: 111→7, 110→6, 000→0.

The result is (671.760)8 or simply (671.76)8.

Q3: Given the multiplication (14)x × (5)x = (74)x, determine the value of the base x.

Solution:

1. Convert the equation to base 10: (1*x1 + 4*x0) × (5*x0) = (7*x1 + 4*x0).

2. Simplify the expression: (x + 4) × 5 = 7x + 4.

3. Solve for x: 5x + 20 = 7x + 4 → 16 = 2x → x = 8.

Q4: If √(41)b = 5, what is the value of the base b?

Solution:

1. First, square both sides of the equation: (41)b = 52 = 25.

2. Convert the base b number to base 10: (41)b = 4*b + 1.

3. Set the two base 10 expressions equal and solve for b: 4b + 1 = 25 → 4b = 24 → b = 6.

Q5: A positive integer N is represented as (35)b in a base b system and as (53)b-2 in a base b-2 system. Find the value of N in base 10.

Solution:

1. Convert both representations of N to base 10:
N = (35)b = 3*b + 5.
N = (53)b-2 = 5*(b-2) + 3.

2. Since both expressions equal N, set them equal to each other: 3b + 5 = 5(b-2) + 3.

3. Solve for b: 3b + 5 = 5b - 10 + 3 → 3b + 5 = 5b - 7 → 12 = 2b → b = 6.

4. Now substitute the value of b back into either expression to find N:
N = 3(6) + 5 = 18 + 5 = 23.
Check with the other expression: N = 5(6-2) + 3 = 5(4) + 3 = 20 + 3 = 23. The value of N is 23.

Q6: In base r, the subtraction (412)r - (133)r results in (257)r. Determine the base r.

Solution:

1. Analyze the rightmost column (the units place): 2 - 3 results in 7. This implies a borrow from the next column.

2. The equation for this column is (2 + r) - 3 = 7.

3. Solve for r: r - 1 = 7 → r = 8.

4. Verification: Check the other columns with base 8.
Middle column: Borrowed from 1, so it's 0. Borrow from 4, so it becomes (0+8) - 3 = 5. Correct.
Leftmost column: Borrowed from 4, so it's 3. 3 - 1 = 2. Correct. The base is 8.
